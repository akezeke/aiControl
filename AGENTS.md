# AI Control

A self-hosted dashboard for keeping track of local Codex and Claude Code sessions. Optimize for fast, efficient use and compact interfaces. Skip explanatory copy, onboarding, redundant headings, and obvious instructions. Prefer familiar icons, short labels, and dense layouts; put secondary details in tooltips. Keep essential status and errors clear.

Alien and Command & Conquer should feel distinct through effects, animation, and interface treatment as well as color. Keep effects lightweight, controls responsive, text readable, and respect reduced-motion preferences.

The repository is public. Keep machine-specific values (hostnames, paths, certificates, credentials) out of the code; they belong in `.local/config.json`, written by `npm run setup`.

Git: work only on `main`. Commit and push directly to `main`; never create branches, worktrees or pull requests.
